# Data Visualization – Module 3

## Overview
This module focuses on Data Visualization using Python.

## Tools Used
- Python
- Matplotlib
- Seaborn
- Google Colab

## Visualizations Created
- Bar Chart
- Line Chart
- Pie Chart
- Histogram
- Scatter Plot

## Key Insights
- Data Science has the highest marks among the subjects.
- Maths has the lowest marks among the subjects.
- The line chart shows variation in marks across subjects.
- The histogram shows the distribution of marks.
- The scatter plot shows a positive relationship between age and marks.

## Project
This project demonstrates how Python visualization libraries can be used to understand data through charts and graphs.
